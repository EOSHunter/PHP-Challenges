# R7 repository context: PHP-Challenges

This is a collection of 2017 PHP practice exercises, organized by `Week13/` and `Week14/`. Week 13 has normal, medium, and hard exercises; the hard exercise builds and deals a card deck in PHP. Week 14 contains basic PHP, HTML form processing, and a database query exercise in `Week14/Challenge2/index.php`.

The exercises are independent examples, not a unified application. Some files are incomplete or explicitly marked as not working. Some Week 14 examples contain embedded database connection details; do not copy or reuse those details.

See [decisions.md](decisions.md) for the current structure and [changes/2017-09.md](changes/2017-09.md) for all five default-branch commits. Coverage ends at `6748cff0d703f6dae42c408d16ea9977cb0eca11`.
